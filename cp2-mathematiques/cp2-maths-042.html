2. Je fais le point

- Qu’avons-nous appris aujourd’hui ?

 

 

 

 

 

 

 

 

TC

- T répond: Nous avons appris à comparer deux

nombres sans outils.

- Comment faire pour comparer deux nombres sans outils ?

U répond: Pour comparer deux nombres sans outils, je suis les étapes suivantes :

Je compare leurs nombres de chiffres. Le nombre le plus grand est celui qui a le plus grand nombre de chiffres.

Si les nombres ont le même nombre de chiffres, je compare d'abord les chiffres des centaines : le nombre le plus grand est celui qui a le plus grand chiffre des centaines.

Si les chiffres des centaines sont les mêmes, je compare les chiffres des dizaines : le nombre le plus grand est celui qui a le plus grand chiffre des dizaines.

Si les chiffres des dizaines sont les mêmes, je compare les chiffres des unités : le nombre le plus grand est celui qui a le plus grand

chiffre des unités.
