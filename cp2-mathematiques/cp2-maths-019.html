Comment effectuer une addition dans un tableau de numération ?

 

 

 

 

 

TC

T répond: Nous avons appris à faire une addition sans retenue avec le tableau de numération.

U répond : Pour effectuer une addition dans un tableau de numération:

On pose dans la colonne des unités, les unités sous les unités, dans la colonne des dizaines, les dizaines sous les dizaines et dans la colonne des centaines, les centaines sous les centaines.

On additionne les unités entre elles, les

dizaines entre elles puis les centaines entre elles.
