2. Je fais le point

- Qu’avons-nous appris aujourd’hui ?

 

 

 

 

TC

- T répond: Nous avons appris à construire un

carré et un rectangle.

- Comment faire pour construire un carré et un sur un quadrillage ?

U répond : Pour construire un carré sur un quadrillage, je compte le même nombre de carreaux pour chaque côté.

Pour construire un rectangle sur un quadrillage, pour les 2 côtés les plus longs, je compte le même nombre de carreaux et pour les 2 côtés les plus courts, je compte aussi le

même nombre de carreaux.
