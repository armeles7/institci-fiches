Situation d’apprentissage

Mariam et Fatim sont des élèves de CP2 de l’EPP… Elles déversent des ordures ménagères derrière leur maison et versent toujours l’eau sale dans la cour. Pour cette raison, leur cadre de vie sent très mauvais. Informé, leur maître décide de faire le cours sur la bonne utilisation des poubelles.

Observent
C’est une poubelle.
C’est une boîte, un récipient où l’on dépose des ordures.
Citent : un seau ; un carton ; un sac plastique ; une fosse à ordures ; une boîte…
On peut mettre : les feuilles, le reste de manger, les ordures, les saletés des balayages, les peaux de bananes…
Activité 2 :
Fait observer les images du livre-élèves pages 58-59.
Comment doivent être les poubelles pour un environnement sain ?
Pourquoi doit-on utiliser les poubelles ?
Comment peut-on entretenir les poubelles ?
Observent
Il faut utiliser les poubelles fermées.
On utilise les poubelles fermées pour :
conserver les ordures dans un lieu sûr ;
empêcher que les odeurs se propagent ;
empêcher la présence des mouches ;
éviter les maladies ;
vivre dans un environnement sain.
Il faut :
laver les poubelles ;
nettoyer les poubelles.		Travail collectif
